# Deep CFR & Interpretable Agent Architecture Diagrams

A collection of comprehensive diagrams explaining the Deep CFR infrastructure, training process, and Interpretable Agent system for poker AI.

## 📊 What's Inside

This repository contains detailed diagrams covering:

1. **Deep CFR Architecture & Training** - How the neural network-based CFR system works
2. **Interpretable Agent Training** - Knowledge distillation process from Deep CFR to decision trees
3. **Complete System Flow** - End-to-end process from training to deployment
4. **Decision Tree Structure** - Example of how decision trees make decisions

## 🎯 Use Cases

- **Presentations**: Use diagrams in slides to explain the system
- **Documentation**: Include in technical documentation
- **Teaching**: Visual aids for explaining poker AI concepts
- **Research**: Reference for understanding the architecture

## 🚀 Quick Start

### Viewing Mermaid Diagrams

1. **Online**: Copy Mermaid code to https://mermaid.live/
2. **VS Code**: Install "Markdown Preview Mermaid Support" extension
3. **GitHub**: Diagrams render automatically in markdown files

### Using Text Diagrams

- Copy text diagrams directly into:
  - PowerPoint
  - Google Slides
  - Keynote
  - Any text editor
